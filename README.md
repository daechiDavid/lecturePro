# LecturePro

온라인 강의 및 발표 시 화면 위에 직접 판서할 수 있는 데스크톱 오버레이 도구입니다.

## 주요 기능

- **화면 판서** - 펜, 형광펜, 지우개로 화면 위에 자유롭게 필기
- **줌 렌즈** - 화면 특정 영역을 확대하여 표시
- **플로팅 메뉴** - 드래그 가능한 미니 컨트롤 패널
- **HUD** - 현재 모드/색상/크기를 상단에 표시
- **듀얼모니터 지원** - 플로팅 버튼이 위치한 모니터에서 전체화면 오버레이
- **커스텀 단축키** - 설정에서 모든 단축키 변경 가능
- **색상 프리셋** - 5개 색상 슬롯, 커스텀 색상 지원

## 단축키 (기본값)

| 단축키 | 기능 |
|--------|------|
| `Ctrl+Alt+A` | 오버레이 켜기/끄기 |
| `Ctrl+Alt+D` | 펜 모드 |
| `Ctrl+Alt+H` | 형광펜 모드 |
| `Ctrl+Alt+E` | 지우개 모드 |
| `Ctrl+Alt+0` | 모드 해제 |
| `Ctrl+Alt+Z` | 줌 렌즈 켜기/끄기 |
| `Ctrl+Alt+C` | 모든 필기 지우기 |
| `Ctrl+Alt+U` | 마지막 획 되돌리기 |
| `Ctrl+Alt+1~5` | 색상 1~5 선택 |
| `Ctrl+Alt+Up/Down` | 펜 굵기 증가/감소 |
| `Ctrl+Alt+Left/Right` | 줌 배율 감소/증가 |

## 사용법

### 트레이 메뉴

앱을 실행하면 시스템 트레이(작업 표시줄 우측)에 아이콘이 나타납니다. 우클릭하면 다음 메뉴를 사용할 수 있습니다:

- **오버레이 켜기/끄기** - 화면 판서 모드 활성화
- **모드 선택** - 펜, 형광펜, 지우개, 모드 해제
- **줌 렌즈 켜기/끄기** - 화면 확대 기능
- **모든 필기 지우기** - 캔버스 초기화
- **설정** - 단축키, 색상, 모니터 설정 창 열기
- **종료** - 앱 종료

### 플로팅 메뉴

오버레이가 켜지면 화면에 플로팅 컨트롤이 나타납니다:

- **ON/OFF 버튼** - 클릭으로 오버레이 토글, 드래그로 위치 이동
- **도구 버튼** - 펜 / 형광펜 / 지우개 / 전체삭제
- **색상 선택** - 프리셋 색상 클릭으로 변경
- **크기 슬라이더** - 현재 도구의 굵기 조절

### 설정 커스터마이징

트레이 메뉴에서 **설정**을 열면 다음 항목을 변경할 수 있습니다:

#### 단축키 변경
- 각 기능의 단축키 항목을 클릭하면 입력 대기 상태가 됩니다
- 원하는 키 조합을 누르면 자동으로 입력됩니다 (예: `Ctrl+Shift+D`)
- **저장** 버튼을 눌러야 적용됩니다
- **기본값 복원** 버튼으로 모든 단축키를 초기값으로 되돌릴 수 있습니다

#### 플로팅 메뉴 위치
- **모니터** - 듀얼모니터 환경에서 플로팅 메뉴가 표시될 모니터를 선택합니다. 오버레이도 선택한 모니터에 적용됩니다.
- **X/Y 좌표** - 플로팅 메뉴의 정확한 위치를 수치로 지정할 수 있습니다

#### 커스텀 색상
- 5개의 색상 슬롯을 각각 클릭하여 원하는 색상으로 변경할 수 있습니다
- 변경 후 **저장**을 누르면 플로팅 메뉴와 단축키(Ctrl+Alt+1~5)에 반영됩니다

## 설치

### Windows

[Releases](https://github.com/daechiDavid/lecturePro/releases)에서 `LecturePro Setup x.x.x.exe`를 다운로드하여 실행합니다.

### 개발 환경에서 실행

```bash
git clone https://github.com/daechiDavid/lecturePro.git
cd lecturePro
npm install
npm start
```

## 빌드

### Windows 설치파일

```bash
npm run build:win
```

`dist/LecturePro Setup x.x.x.exe` 파일이 생성됩니다.

### macOS

```bash
npm run build:mac
```
